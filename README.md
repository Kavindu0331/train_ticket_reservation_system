# Train Reservation System — Member 4

This folder contains the project structure for the **Admin Panel and Booking History** module.

## Member 4 responsibilities

1. Admin dashboard
2. View all trains
3. Add a train
4. Update a train
5. Remove or deactivate a train
6. Cancel a scheduled journey
7. View customer booking history
8. View and edit the admin profile
9. Connect these features to the shared MySQL database

## Technology

- Java 17
- Maven
- JDBC
- MySQL/MariaDB through XAMPP
- Swing for a simple desktop interface

## Project folders

- `model` — Java objects representing database records
- `dao` — database queries
- `service` — validation and application rules
- `ui` — admin screens
- `util` — database connection helper
- `resources` — database settings
- `database` — shared SQL schema

All Java files are placeholders. Add implementation after agreeing on the shared classes and database with the other members.
